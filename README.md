Запуск приложения без UDP-модуля:

```bash
go run .
```

UDP-модуль отключён по умолчанию. Чтобы отправлять каждый CRSF frame на UDP-сервер:

```bash
go run . -udp-enabled=true -udp-address=192.168.1.50:9000
```

`-udp-address` принимает адрес и порт назначения. Каждый пакет отправляется одной UDP-датаграммой; UART-вывод при этом продолжает работать независимо.
